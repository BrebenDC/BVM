TradeLog — Cloud Sync Setup
1
Maak een gratis Firebase project aan
Firebase is Google's gratis cloud database. Je data sync dan automatisch tussen al je apparaten.
🔗 Ga naar console.firebase.google.com ↗

Klik op + Project toevoegen → geef het een naam → maak aan.

Dan: Realtime Database → Create Database → Start in test mode.
En: Authentication → Get started → Email/Password inschakelen.
2
Kopieer je Firebase config
In Firebase console: Project instellingen (tandwiel) → scroll naar "Your apps" → klik op web-icoon </> → App registreren → kopieer de firebaseConfig object.
const firebaseConfig = { apiKey: "AIza...", authDomain: "project.firebaseapp.com", databaseURL: "https://project-rtdb.firebaseio.com", projectId: "project", storageBucket: "project.appspot.com", appId: "1:xxx:web:xxx" };
